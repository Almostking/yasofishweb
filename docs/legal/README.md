# Borradores comerciales y legales

Los siete HTML son textos propios de revisión, no documentos definitivos ni una aprobación jurídica. Las condiciones del negocio pendientes no se inventaron. En LocalWP se crean como páginas navegables con aviso visible de borrador y metadatos que impiden presentarlas como aprobadas fuera del entorno local. No se asignan automáticamente como términos aceptados del checkout.

Fuentes primarias consultadas el **27 de octubre de 2026**:

- [SERNAC: información de garantía en comercio electrónico](https://www.sernac.gov.cl/portal/604/w3-article-89178.html): referencia para seis meses y alternativas legales cuando corresponda.
- [SERNAC: garantía y retracto](https://www.sernac.gov.cl/portal/618/w3-propertyvalue-8062.html): referencia para retracto y confirmación escrita, sujeto a sus condiciones y excepciones.
- [SERNAC: derechos en comercio electrónico](https://www.sernac.gov.cl/portal/604/w3-propertyvalue-20982.html): información precontractual que debe concretarse antes de habilitar compras.
- [SII: transferencia y documento tributario](https://www.sii.cl/preguntas_frecuentes/factura_electronica/001_003_7869.htm): emisión del documento aplicable, sin confundirlo con un comprobante bancario.
- [BCN: Ley 21.719](https://www.bcn.cl/leychile/Navegar?idNorma=1209272): transición de protección de datos; revisar el marco vigente en la fecha real de lanzamiento.

La lectura disponible de las fuentes incluyó índices oficiales y contenido recuperado; algunas páginas SERNAC agotaron el tiempo de carga directa. Los borradores citan esos recursos y quedan sujetos a revisión del titular/asesoría antes de publicación. No se añadieron beneficios voluntarios, tarifas ni renuncias de derechos.

Editar y aprobar desde Páginas → Revisión comercial YASOFISH. El control de aprobación exige permiso de edición y nonce válido. Los datos bancarios no forman parte de estos archivos.
