# YASOFISH Chile

Demostración estática de tienda de pesca. Productos, precios y pagos ficticios; no se generan cobros ni pedidos reales.

Demo: https://almostking.github.io/yasofishweb/

Los archivos HTML, CSS, JavaScript e imágenes de la raíz corresponden a la carpeta dist del proyecto original. GitHub Pages publica main / (root). Para actualizar, reemplaza estos archivos y confirma los cambios.

El archivo yasofish-storefront-child-source.zip contiene el código del tema hijo WooCommerce y necesita WordPress, WooCommerce y Storefront. No forma parte del servidor de demostración.
